# 座席連絡（PWA）

座席表の画像にピンを立てて、自分の席を画像で共有できるファン向けメモアプリです。
スマホのホーム画面に追加すると、アプリのように使えます（オフライン対応）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | アプリ名・アイコン・テーマ色の設定 |
| `sw.js` | オフライン動作用（Service Worker） |
| `icon-192.png` / `icon-512.png` | アプリアイコン |
| `icon-maskable-512.png` | Android用アイコン |
| `apple-touch-icon.png` | iPhone用アイコン |

すべて相対パスなので、リポジトリ直下でもサブディレクトリでもそのまま動きます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（Public にする）
2. このフォルダの中身をすべてアップロードする
   - リポジトリの「Add file」→「Upload files」に、ファイルをまとめてドラッグ＆ドロップ
   - `index.html` がリポジトリの一番上の階層に来るようにしてください
3. 「Commit changes」を押す
4. リポジトリの **Settings** → 左メニューの **Pages** を開く
5. **Source** を「Deploy from a branch」、**Branch** を `main` / `/(root)` にして **Save**
6. 1〜2分待つと、ページ上部に公開URLが表示されます

公開URLの形式:

```
https://（ユーザー名）.github.io/（リポジトリ名）/
```

GitHub Pages は自動的に HTTPS になるので、PWA として問題なく動作します。

## ホーム画面に追加する方法

**iPhone（Safari）**
共有ボタン → 「ホーム画面に追加」

**Android（Chrome）**
メニュー（︙）→ 「アプリをインストール」または「ホーム画面に追加」

## アプリを更新したとき

`index.html` などを更新したら、`sw.js` の1行目付近にある

```js
const CACHE_VERSION = 'v1';
```

の数字を `v2`, `v3` … と上げてください。
古いキャッシュが自動で削除され、利用者に新しい版が届きます。
（この数字を上げないと、古い画面が表示され続けることがあります）

## 使い方

1. タイトルの「会場名を入力」の部分をタップして会場名を入れる
2. 「座席表の画像を選ぶ」から、座席表の画像を読み込む
   - スマホなら、座席表のスクリーンショットがそのまま使えます
3. 座席表をダブルタップしてピンを立てる
   - 「だいたいここ」…おおまかな目印
   - 「ここ！」…座席をピンポイントで指すマーク（色を変えられます）
4. 座席メモ・公演名・日時などを入力
5. 「全体を保存」「表示範囲を保存」「Xに投稿」から共有

入力した会場名・アイコン画像・座席表は端末内に保存され、次回起動時も引き継がれます。

## ご注意

- 本ツールはファンメイドのメモ作成アプリです。各会場・主催者とは関係ありません
- 座席表の画像は、利用規約上問題のない範囲でご利用ください
- 保存されるデータは利用者の端末内のみで、サーバーには送信されません
